# BukuBaik — Website Penggalangan Dana Buku

Landing page untuk gerakan penggalangan dana dan donasi buku.

## Fitur
- Responsive / mobile-first
- CTA donasi dana dan buku
- Bagikan kampanye menggunakan Web Share API
- Bagian transparansi
- Placeholder aman untuk rekening/QRIS sampai data resmi tersedia
- Siap di-host sebagai static site di Vercel

## Sebelum dipublikasikan
Ganti placeholder pada bagian **Informasi donasi** dengan data rekening atau QRIS yang benar dan terverifikasi. Jangan menambahkan informasi pembayaran yang belum dikonfirmasi.

## Deploy
Project ini tidak memerlukan build command. Import repository ke Vercel dan deploy sebagai static site.
